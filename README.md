# marketing-unit-economics
Dynamic marketing unit economics model built with Excel

Marketing Unit Economics

About the Project

An educational data analytics project focused on building a dynamic marketing unit economics model using Microsoft Excel.

The goal is to understand how customer acquisition costs, conversion rates, revenue, and product costs affect marketing profitability.

Project Objectives

Calculate marketing expenses across acquisition channels.

Analyze conversion rates and Customer Acquisition Cost (CAC).

Calculate revenue and cost of goods sold.

Evaluate gross profit and marketing efficiency.

Build a dynamic financial model using Excel formulas.
